# Pokémon TCG Promo

Landing com quiz para captar **leads quentes** (quem já compra TCG) no grupo WhatsApp de ofertas de cartas Pokémon no Mercado Livre. O convite do grupo só aparece depois da qualificação no n8n.

## Stack

- Astro
- TypeScript
- Tailwind CSS

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:4321](http://localhost:4321).

## Scripts

| Comando | Descrição |
|---|---|
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm run preview` | Preview do build |
| `npm run astro` | CLI do Astro |

## Conteúdo editável

Links e nome ficam em `src/lib/site.ts` (ou nas variáveis `PUBLIC_*` do `.env`).

Artwork das criaturas: `public/pokemon/` (PokéAPI official artwork).

## Aviso

As compras acontecem nas plataformas e vendedores. O grupo só compartilha ofertas.
